# Siyao Chen academic homepage

This is a zero-build static site prepared for GitHub Pages. It does not copy the source code or visual assets of `ActiMecha/hit` or any other personal website.

## Publish as the primary GitHub Pages site

1. On GitHub, create a **public** repository named exactly `scottchensiyao-afk.github.io`.
2. Upload the contents of this folder to the repository root and commit them to the `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will publish the page at `https://scottchensiyao-afk.github.io/` after the deployment completes.

## Before publishing

- Replace the selected-publication entries with checked DOI links and final bibliographic metadata.
- Add a professional portrait only if you want one publicly visible.
- Add a CV PDF only after removing private contact details that should not be public.
- If you later use a custom domain, add a `CNAME` file and configure DNS through the domain registrar.
